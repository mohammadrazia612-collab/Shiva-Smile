# Shiva Smile Dental Care Hospital 🏥✨

> Premium, Apple-inspired website for **Shiva Smile Dental Care Hospital**, located in Azam Pura, Siddipet, Telangana 502103, India. Rated 4.9/5 on Google with comprehensive multi-speciality dental healthcare services.

---

## 🌟 Features & Highlights

- **Aesthetic Design**: Minimal, spacious, typography-focused Apple-inspired visual presentation with harmonious micro-interactions.
- **Interactive Physics Cluster**: Draggable physics nodes for core specialties (Dental Implants, Cosmetic Dentistry, Pediatric Dentistry, Emergency Care, and Periodontal Gum Health).
- **Interactive Before/After Slider**: Real-time interactive split slider for dental aesthetic restorations.
- **6-Layer Hero Architecture**: Modular structure (`HeroBackground`, `HeroMedia`, `HeroSpline3D`, `HeroEffects`, `HeroContent`, `HeroCTA`).
- **Concierge Appointment Modal**: Interactive booking form with validation, preferred time window selection, and instant confirmation reference generation.
- **WhatsApp Direct Connect & Direct Call**: One-tap direct appointment inquiry via WhatsApp and clinic helpline (`+91 83098 64006`).
- **Comprehensive Clinic Flow (16 Key Sections)**:
  1. Responsive Navigation Bar with Mobile Drawer
  2. Apple-Style Cinematic Hero Section
  3. Popping Animated Statistics
  4. Quick Services / Specialties Grid
  5. Interactive Physics Service Cluster
  6. In-Depth Main Treatments
  7. Interactive Before & After Smile Slider
  8. Clinic Story & 4 Pillars of Excellence
  9. Advanced Dental Technology Cards
  10. Smile Transformations Gallery
  11. Patient Comfort & Atmosphere Features
  12. Multidisciplinary Doctors & Clinical Specialists Team
  13. Verified Patient Testimonials
  14. Comprehensive Dental Care FAQ Accordion
  15. Location, Operating Hours & Contact Section with Google Maps
  16. High-Fidelity Footer with Quick Links & Back-to-Top

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: Pure Modern CSS (CSS Grid, Flexbox, Custom Properties, Glassmorphism, Micro-animations)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations & Effects**: `canvas-confetti`
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *Inter*)
- **SEO**: Semantic HTML5, Schema.org `Dentist` JSON-LD Structured Data, Open Graph tags

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/mohammadrazia612-collab/Shiva-Smile.git
cd Shiva-Smile
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
The production bundle will be generated in the `dist/` directory.
